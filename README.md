# Dinobox - Frontend

Frontend del proyecto Dinobox, desarrollado con React, Axios y Bootstrap para la asignatura Desarrollo Fullstack II.

## Funcionalidades

- Registrar nuevas encomiendas.
- Buscar encomiendas por código de seguimiento.
- Consultar y actualizar estados.
- Listar y eliminar encomiendas.

## Ejecución

1. Tener el backend de Dinobox ejecutándose.
2. Abrir el proyecto en VS Code.
3. Ejecutar `npm install` y luego `npm start`.

El frontend se abre en `http://localhost:3000` y se conecta al backend mediante Axios.
